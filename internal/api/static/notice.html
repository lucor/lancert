Notice Status

Service notice

Certificate issuance temporarily suspended

Lancert is an experimental service for obtaining publicly trusted TLS certificates for services running on private networks.

We identified a potential compliance issue involving the way private keys are distributed by the current service. As a precaution, certificate issuance, renewal, and downloads have been temporarily suspended while we seek clarification from Let’s Encrypt.

Existing DNS records remain operational.

Existing certificates and keys should not be used for new deployments while the review is ongoing. We will publish an update if further action is required.

Still available: the Lancert website, service status, authoritative DNS, and existing DNS records.

Certificate operations have been suspended since 29 July 2026.
